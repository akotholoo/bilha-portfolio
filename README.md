# Bilha Akoth — Portfolio Website

A responsive personal portfolio built with HTML, CSS, and JavaScript.

## Files
- `index.html` — website content
- `style.css` — pink feminine design and responsive layout
- `script.js` — mobile navigation and current year
- `Bilha-CV.pdf` — add your CV here before publishing (optional)
- `images/` — add project screenshots or a professional photo here (optional)

## Run locally
1. Extract this folder.
2. Open `index.html` in your browser, or open the folder in Visual Studio Code.
3. Optional: use the VS Code Live Server extension to preview edits.

## Personalise before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html` with your professional email.
2. Replace the LinkedIn and GitHub placeholder URLs with your profile URLs.
3. Update education dates and attachment dates.
4. Check each skill and keep only skills you can explain honestly.
5. Change the project cards to match the real status of your work. The included project ideas are labelled as concepts/planned builds where appropriate.
6. Add a CV PDF named `Bilha-CV.pdf` in this folder if you want to link it from the page. To add a CV button, add this inside the hero actions:
   `<a class="button button-secondary" href="Bilha-CV.pdf" download>Download CV ↓</a>`
7. Add real GitHub links or project demo links when available.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new repository named `yourusername.github.io` (replace `yourusername` with your GitHub username).
2. Upload `index.html`, `style.css`, `script.js`, and any assets to the repository's root.
3. Open the repository's **Settings → Pages**.
4. Under the build/deployment section, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. If the repository is named `yourusername.github.io`, GitHub Pages usually publishes at `https://yourusername.github.io/`.
5. Wait for deployment and open the URL shown in Settings → Pages.

For a project repository with a different name, the URL is typically `https://yourusername.github.io/repository-name/`.

## Notes
- Basic GitHub Pages hosting is free for public repositories.
- This is a static website. A real booking system, database, login, or payment processing requires a backend and secure provider integration; don't collect card details directly in this static portfolio.
- Review contact details and public information before publishing.
